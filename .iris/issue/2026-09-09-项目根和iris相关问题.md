项目根 右边的加号，没有iris agent选项，然后是项目根终端页，点击用irisagent打开之后，没有切过去，你修复一下

***

## 根因（agent 写回）

两个问题都不在主进程，都在渲染层的入口没接线。

**1. 左栏「项目根」右侧加号没有 Iris Agent 选项**

右栏的会话启动菜单（`RightPane`）在 `settings.experimental.irisAgent` 打开时
会插入「用 Iris Agent 打开」，但左栏工作区头部的加号走的是另一个组件
`LensTree.NewWorkspaceSessionButton`，它只渲染 `LauncherMenuItems`（普通终端
启动器清单），从未读过实验开关、也没有 `openIrisAgent` 分支。根工作区与子工作区
共用这一个组件，所以两处都缺。

**2. 「项目根」终端页点「用 Iris Agent 打开」不切换**

右栏是**锚点驱动**的（同 issue 2026-06-16）：只显示
`sessionProjectionAnchorKey(session.anchor) === anchorKey` 的会话，而 `anchorKey`
完全由中栏 `view` 推导。

刚打开项目时 `view = { kind: 'doc', path: null }`（`projectStore.handleOpened`），
此时 `RightPane` 的 `isHub === false`、`selectedPath === null`，于是
`anchorKey === null`：右栏标题显示「项目根」、正文是启动台（launch pad）。

普通终端的启动器 `session-actions.ts` 在 dispatch `session.open` **之前**先把视图
导航到会话锚点（`selectRoot/selectWorkspace/selectDoc`），所以新终端必然落进右栏
当前锚点。而 `openIrisAgent` 只做了「创建会话 → 写 store → 在**会话自己的**锚点
键下选中」，**从不导航视图**：

* 会话锚点是 `ws:.iris`，选中键也是 `ws:.iris`；

* 但当前 `view` 还是 `doc:null`，右栏算出的 `anchorKey` 是 `null`，
  `visibleItems` 直接为空；

* 结果：左栏「项目根」下确实多了一行 Agent 会话，右栏却仍停在启动台。

`doc:null` 只是最容易踩到的入口；任何「当前视图锚点 ≠ 会话锚点」的情形
（集合视图、todo 面板、另一个文档/工作区）都同样不切换。

## 修复

**A.** **`src/renderer/lib/iris-agent-actions.ts`** **—** **`openIrisAgent`** **先导航、再建会话**

与 `session-actions.ts` 同一套规则：flush 之后，按锚点把中栏视图带过去
（document → `projectStore.selectDoc(path)`；workspace `.iris` → `selectRoot()`；
其他 workspace → `selectWorkspace(path)`），导航失败（编辑器冲突等）就直接放弃，
不创建会话；然后才调 `IRIS_AGENT_OPEN`、写 store、在会话自己的锚点键下选中。
选择集中在这一个函数里，所有入口（右栏启动台、右栏 +、左栏 +、Fork）共享。

**B.** **`src/renderer/components/lens/LensTree.tsx`** **— 工作区加号补齐 Iris Agent**

`NewWorkspaceSessionButton` 读 `settings.experimental.irisAgent`，开启时在启动器
清单之前插入一项，点击即 `openIrisAgent({ kind: 'workspace', path: workspacePath })`
（导航与选中交给 A）。根工作区与子工作区同时生效，与「终端平权」一致。

**C.** **`src/renderer/components/layout/RightPane.tsx`** **— 文案与选择去重**

硬编码的「用 Iris Agent 打开」换成既有 i18n 组合
`t('layout.openWith', { agent: t('settings.irisAgent') })`（zh：用 Iris Agent 打开 /
en：Open with Iris Agent，与设置页 `enableIrisAgentHint` 的描述一致），左栏新增项
复用同一文案；同时删掉 `spawnIrisAgent` 里用陈旧 `anchorKey` 的二次选中，选择只由
`openIrisAgent` 负责。

## 实现结果

* `src/renderer/lib/iris-agent-actions.ts`：`openIrisAgent` 新增按锚点导航（导航在
  前、`IRIS_AGENT_OPEN` 在后），导航被拒即返回 `null`、不创建会话。

* `src/renderer/components/lens/LensTree.tsx`：`NewWorkspaceSessionButton` 读取
  `experimental.irisAgent`，新增「用 Iris Agent 打开」菜单项（`DropdownMenuItem`），
  点击调用 `openIrisAgent` 走工作区锚点。

* `src/renderer/components/layout/RightPane.tsx`：两处硬编码文案改为
  `t('layout.openWith', { agent: t('settings.irisAgent') })`；`spawnIrisAgent` 只调用
  `openIrisAgent`，不再用渲染时的旧 `anchorKey` 二次选中。

* 新增 `src/renderer/lib/iris-agent-actions.test.ts`：回归覆盖「`doc:null` 启动台点
  用 Iris Agent 打开 → 视图切到 root hub、会话在 `ws:.iris` 下被选中」，以及
  「导航被编辑器拒绝时不创建会话」。
