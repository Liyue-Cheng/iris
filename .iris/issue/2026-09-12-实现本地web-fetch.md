## 目标

在 Iris 内置一个无需 Docker、Python、Playwright 或外部 Gateway 的本地 `web_fetch` 工具，参考 OpenCode 的实现方式，为 Agent 提供网页内容读取能力。

## 范围

- 仅允许 `http://` 和 `https://` URL。
- 支持 `markdown`、`text`、`html` 三种输出格式，默认返回 Markdown。
- 支持请求超时和响应体大小限制。
- 仅处理文本类响应；拒绝图片和不支持的二进制内容。
- HTML 使用 `htmlparser2` 提取文本，使用 `turndown` 转换 Markdown。
- 对重定向目标重新执行 URL 安全校验。
- 网页内容标记为不可信外部输入，不能改变 Agent 的工具策略或系统指令。

## Iris 接入位置

- 在 `IrisToolHostOperations` 增加 web fetch 能力。
- 在 `createIrisPiToolDefinitions()` 注册 `web_fetch` 工具。
- 在 worker/tool host 中传递 AbortSignal，支持取消和超时。
- 网络请求复用现有 `undici` 和代理能力。

## 建议参数

```text
url: string
format?: markdown | text | html
timeoutSeconds?: 1..120
maxBytes?: 64 KiB..5 MiB
```

## 安全要求

- 阻止 localhost、回环地址、链路本地地址和常见私网地址。
- 限制最大响应大小，避免内存占用失控。
- 限制超时并支持取消。
- 校验 Content-Type，拒绝图片和非文本资源。
- 不在日志、工具结果或错误中暴露敏感请求头。

## 验收标准

- [ ] 可以读取普通 HTML 页面并返回可读 Markdown。
- [ ] 可以返回纯文本和原始 HTML。
- [ ] 超时、超大响应、非文本响应能返回结构化工具错误。
- [ ] 重定向到私网地址会被阻止。
- [ ] 工具调用可以被取消。
- [ ] 不需要用户安装或启动 Docker、Python、Playwright 或外部服务。
- [ ] 依赖许可证和 OpenCode 参考代码归属得到记录。
