HTTP 400 Bad Request {"error":{"message":"The \`reasoning\_text\` in the thinking mode must be passed back to the API.","type":"invalid\_request\_error","param":null,"code":"invalid\_request\_error"}}

## 诊断（2026-09-11）

这是 DeepSeek 思考模式的上下文回放校验错误，不是网络或鉴权错误。DeepSeek 要求后续请求中的历史 assistant 消息带回对应的 `reasoning_text`（或等价的 reasoning 内容）；当前 Iris 的 provider 上下文清洗只保留可见文本和 tool call，遇到中断消息时还会主动丢弃 thinking 块，因此在“继续上一轮对话”时形成了缺少 reasoning 内容的 assistant 历史，API 返回 400。

触发条件通常是：启用 DeepSeek 的思考/推理模式后，中断、切换模型，或从旧会话继续发送消息。新会话且关闭思考模式一般不会触发。

关联实现：`src/main/agent/pi-adapter.ts` 中的 `normalizeIrisProviderContext` / `providerSafeAssistantText` 会移除 thinking 块；底层 `@earendil-works/pi-ai` 已提供 DeepSeek 所需的 `requiresReasoningContentOnAssistantMessages` 兼容选项，但当前项目没有显式补齐历史消息字段。
