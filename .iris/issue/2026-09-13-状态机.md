现在agent经常忘记设置issue的状态机，你看看是不是我们的prompt写的不好，你检查一下

## 检查结果（2026-09-13）

已检查 `src/main/iris-templates.ts` 中注入的 `<iris-software>` 提示词、`src/main/agent/prompt.ts` 基础提示词，以及现有 issue 记录。当前提示词确实描述了状态集合和部分终态限制，但没有把“何时必须切换状态”写成明确、可执行的流程，因此 Agent 容易在整个任务期间保持 `Todo`。

### 已有规则

- issue 状态集合已列出：`Todo`、`In Progress`、`In Review`、`Blocked`、`On Hold`、`Done`、`Canceled`。
- 新 issue 默认从 `Todo` 开始。
- 用户未明确要求时，不得擅自设置 `Done`、`Canceled`、`On Hold`。
- 工作完成、待用户验收时允许设置 `In Review`。
- 围绕焦点 issue 工作时，应把计划、结果和验证证据追加回 issue。

### 缺口

1. 没有明确要求 Agent 在开始实际调查、设计或实现时，将 `Todo` 更新为 `In Progress`。
2. 不应要求 Agent 自主设置 `Blocked`；该状态通常由用户手工维护，或仅在用户明确要求时设置。
3. 没有把 `In Progress → In Review` 的时机写成完成条件（代码已改、检查已跑、剩余事项转为复选框）。
4. “允许移动到 In Review”语气偏弱，容易被模型理解为可选动作；状态更新也没有被列入任务收尾检查清单。
5. `src/main/agent/prompt.ts` 只有通用协作原则，没有补充状态机行为；实际依赖较长的 `<iris-software>` 文本，状态要求在上下文中不够醒目。

### 建议的提示词改文案

在“Do not mark an issue …”之后增加一段短流程：

> When work is requested for an existing issue, update its `status:` to `In Progress` before substantive investigation or edits and keep it there while work is ongoing. When the requested work is complete and only human review, verification, or approval remains, set `In Review` and add one unchecked task per remaining item. Do not set `Blocked`, `Done`, `Canceled`, or `On Hold` on your own; make those transitions only when the user explicitly requests them.

同时在基础 Agent prompt 增加一句高优先级提醒：

> For work anchored to an existing issue, automatically maintain only the `Todo` → `In Progress` → `In Review` workflow and write the transition and evidence back to that issue. Set other issue states only when the user explicitly asks.

这属于低风险的提示词澄清，不改变状态集合、工具协议或运行时行为。当前仅完成审阅和记录，尚未修改 canonical prompt 代码。

## 规则收窄与实现（2026-09-13）

按用户决定，移除 Agent 自主设置 `Blocked` 的语义。Agent 自动维护的状态流仅为：`Todo` → `In Progress` → `In Review`。

- 开始实质性调查、设计或修改前，将现有 issue 设为 `In Progress`。
- 工作完成、只剩人工评审/验证/审批时，设为 `In Review`，并为每项待处理事项添加未勾选任务。
- `Blocked`、`Done`、`Canceled`、`On Hold` 等其他状态不得自作主张设置，仅在用户明确要求时处理。

已同步修改：
- `src/main/iris-templates.ts` canonical `<iris-software>` 提示词。
- `src/main/agent/prompt.ts` 基础 Agent 提示词。

验证：`src/main/agent/prompt.test.ts` 与 `src/main/software-prompt.test.ts` 共 11 项通过。
