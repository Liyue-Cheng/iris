## 结构重整方案

当前问题的根源是右侧区域内部又嵌套了一套可调整面板组，导致左中间隙属于外层背景，而中右间隙属于内层卡片背景。更合理的结构是让主页三栏始终属于同一个平级的 shell：

```text
页面根容器（页面背景色 + 统一内边距）
└── 三栏布局容器（统一 gap）
    ├── 左栏卡片
    ├── 中栏卡片
    └── 右栏卡片
```

结构原则：

- 三个卡片必须是同一个水平面板组的直接子项。
- 所有卡片之间的空白都由同一个父容器的 `gap` 产生，间隙颜色统一显示页面背景色。
- 拖拽手柄只负责调整宽度，不再承担视觉分隔线；视觉间隙由父容器统一提供。
- 左栏、中栏、右栏各自拥有 `overflow-hidden`、圆角、边框和 `bg-card`，不再把中栏和右栏包在一个“右侧大卡片”中。
- 文档视图需要中栏内部再进行编辑器/终端分栏时，应将这视为中栏卡片内部的局部布局；外层三卡片的边界和颜色不受内部布局影响。
- 集合视图、待办视图等特殊页面也应复用同一层级模型，只替换卡片内容，不改变卡片层级。

推荐的组件职责：`ThreePane` 只负责三卡片 shell 和统一间距；各 Pane 组件只负责自己的卡片内容；需要二次分栏时，由中栏卡片内部的专用布局组件负责。这样可以保证布局关系稳定，也避免不同视图切换时出现不同的背景和间隙来源。

## 方案修正

根据新的布局要求，父级三栏容器不再设置 `gap`、统一 `padding` 或统一的视觉间距。它只负责：

- 将左栏、中栏、右栏作为三个并列的直接子项放入同一个可调整布局中。
- 提供宽度调整能力和整体高度约束。
- 不参与卡片背景、边距和栏间空白的绘制。

每个栏自行控制自己的视觉边界：

- 卡片的圆角、边框、阴影和背景由对应 Pane 自己声明。
- 卡片与相邻卡片之间的空白由该 Pane 的外边距或内部包装元素控制。
- 卡片内容与卡片边界之间的距离由该 Pane 自己的 `padding` 控制。
- 不同页面可以按需要使用不同的边距和内边距，而不会被父级布局强制统一。

调整后的目标结构是：

```text
三栏布局容器（只负责排列和尺寸）
├── 左栏面板（自己控制 margin / padding / 卡片样式）
├── 中栏面板（自己控制 margin / padding / 卡片样式）
└── 右栏面板（自己控制 margin / padding / 卡片样式）
```

关键点是三个栏仍然必须是同一布局组的平级子项，但间距的所有权下沉到各栏自身。这样既能消除嵌套面板造成的颜色差异，又保留每个栏独立调整间距的自由度。
