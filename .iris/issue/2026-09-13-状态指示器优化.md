# 状态机和状态指示器优化

已完成“issue 保持原有状态机、其他类型文档统一使用 Active / Backlog”整改。

## 实施内容

- 共享状态模型新增非 issue 文档语义：`status`、`report`、`misc` 均使用 `Active` / `Backlog`。
- 新建文档模板：issue 默认 `Todo`，其他文档默认 `Active`。
- 编辑器状态菜单：issue 显示七态状态机，非 issue 文档显示 `Active` / `Backlog`。
- 状态变更副作用：非 issue 文档也经过统一状态转换规划；进入 `Backlog` 时关闭关联会话，未知值保持可见且不触发副作用。
- 左侧镜像：非 issue 文档按统一活动性规则展示，`Backlog` 默认隐藏；issue 仍保留原有活动 issue 与会话锚定规则。
- Iris 软件协议文本已同步，避免实现与注入规则不一致。
