## 补充说明（2026-10-24）

业务逻辑我们不可能"抄"他们的，我的意思主要是视觉效果设计。我们现在的布局是一个容器里放三个卡片，但他们的布局不是这样的：左栏和中栏好像是用竖线隔开，右栏有明显的突出层次效果。不考虑业务逻辑，只调研三栏的视觉效果。

## 视觉调研（第二版，2026-10-24）：只看三栏的视觉层次

> **范围**：只看分栏的视觉处理，包括底色、分隔、浮层和圆角，不涉及任何功能或业务逻辑。
>
> **方法**：在附图原图（1440×1178，窗口占 x 71–1368）上逐像素取色、扫描边界。
>
> **单位**：下文的「px」都指这张图的像素。图是转载后缩放过的，换算到 CSS 像素大约要除以 1.5～2，所以请只看比例。JPEG 压缩会让极淡的线条略有失真。assets 里的三张 jpg 是同一张图。

### 1. 结论：两层，而不是三张卡片

```
 截图（Claude）                                Iris 现状
┌───────────┬──────────────────┬╭─────────╮┐  ┌──────────────── TitleBar ────────────────┐
│ ●●●       │ 标题  Overview   ││ 面包屑   ││  ├──────────────────────────────────────────┤
│           │                  ││          ││  │╭───────╮ ╭──────────────╮ ╭───────────╮│
│  左栏     │     中栏          ││  右栏    ││  ││ 左栏   │ │    中栏       │ │  右栏      ││
│ （底面）  │   （底面）        ││ （浮层） ││  ││ 卡片   │ │    卡片       │ │  卡片      ││
│           │                  ││          ││  │╰───────╯ ╰──────────────╯ ╰───────────╯│
└───────────┴──────────────────┴╰─────────╯┘  └──────────────────────────────────────────┘
      ↑ 1px 极淡竖线             ↑ 四周留边、细边框、淡阴影              ↑ 三张平级圆角卡片
```

- **截图**：左栏和中栏是**同一张「纸」**，只用一根竖线隔开。右栏是**放在这张纸上的一块浮起面板**。视觉上分成「底面层」和「浮层」两个层级，右栏因此被突出。
- **Iris 现状**：外面一圈 `bg-card` 衬底，里面放三张相同的 `rounded-lg bg-background shadow-sm` 卡片。卡片之间是 4px 宽的拖拽条，条中间有一根淡线。三栏地位相同，没有主次。
  - 布局：`src/renderer/components/layout/ThreePane.tsx:159-177`
  - 拖拽条：`src/renderer/components/ui/resizable.tsx:31`

### 2. 逐项测量

| 部位 | 测量结果 | 说明 |
|---|---|---|
| 左栏底色 | `#fbfbf9` | 中性略暖的白 |
| 中栏底色 | `#fcfcfa` | 与左栏只差 1 个色阶，肉眼看是同一种颜色 |
| 左/中分隔 | 1 根 1px 竖线 `#f3f3f1`，只比底色暗约 3% | 从窗口顶贯穿到底，没有间隙、圆角或阴影。在 y=150 到 1080 之间多处取样，颜色都一样 |
| 标题行 | 没有独立的标题栏色带，标题行下方也**没有横向分隔线** | 红绿灯、侧栏按钮、项目名、Overview 按钮直接放在底面上 |
| 右栏外边距 | 上、右、下各约 5px，左侧没有明显间隙 | 卡片顶边 y≈77（窗口顶 71），底边 y≈1100（窗口底 1106），右边 x≈1362（窗口右边 1368） |

| 右栏圆角 | 约 8～10px | 明显小于窗口外圆角（约 20px） |
| 右栏高度 | 一直顶到窗口顶部 | 右栏占用了标题栏那一行，自带的头部（面包屑和图标）就是它的标题行 |

### 3. 为什么它显得「有层次」

1. **只有一处被抬起**。三张卡片平均用力，等于没有重点；截图只抬起右栏，层次差就出来了。
2. **分隔用最轻的手段**。左/中之间只有一根对比度约 3% 的线，标题行下和面板头部下都没有线。线越少，浮层的边缘越显眼。
3. **浮层的几个要素同时出现，而且每个都很弱**：四周留一点边、一根细边框、一层很淡的阴影，再加上填充略亮。单看哪一项都不明显，叠在一起就有了清楚的前后关系。
4. **没有衬底**。Iris 现在的 `bg-card` 衬底让所有面板都像嵌在凹槽里；截图里底面本身就是左栏和中栏的背景。
5. **圆角分级**。窗口约 20px，浮层约 8～10px，内容卡片和按钮更小。圆角随层级递减，整体显得规整。

### 4. 映射到 Iris 时要注意的地方（只谈视觉）

- **Windows 标题栏冲突**。截图是 macOS，窗口按钮在左上角，所以右栏能顶到窗口顶部。Iris 在 Windows 上把窗口按钮放在右上角（`TitleBar.tsx:60-119`），右栏顶到顶部会和它们冲突。有三种处理方式：
  1. 保留 40px 标题行，但让它与底面同色、不加分隔线，右栏浮层从标题行下方开始。
  2. 把窗口按钮挪进右栏浮层的头部。
  3. 右栏浮层顶部给窗口按钮让出一块位置。

  第一种最稳。
- **单栏视图**。hub 视图（终端全宽）、todos、collection 都不是「左 + 中 + 右」的结构，需要分别决定谁当浮层。一个自然的规则是：**终端和详情面板永远浮起，文档、列表和导航永远在底面**。
- **深色主题的层级**。浅色模式下浮层更白；深色模式的惯例是浮层更亮一点、阴影基本看不见，主要靠边框。14 套主题都需要补：
  - 一个浮层底色 token，例如 `--surface-raised`；
  - 一档比现有 `--border` 稍重的浮层边框。

  现有的 `--border` 和 `--border-subtle` 两档，正好可以用作左/中分隔线。
- **终端背景**。右栏浮层里是 xterm，它的背景色在 `src/renderer/theme/xterm-themes.ts` 里单独维护。浮层底色变了，这里也要同步，否则浮层里会出现一块颜色不一样的终端区域。
- **拖拽条**。左/中之间可以继续用现有的 1px 线（`resizable.tsx` 的 `after:` 伪元素），只需调淡。中/右之间不再画线，浮层边框本身就是边界，拖拽热区放在浮层左边缘附近即可。

### 5. 可做的视觉改动清单（供选择，未实施）

1. 去掉 `ThreePane` 的 `bg-card` 衬底，以及左、中两栏的卡片外壳，让它们直接铺在 `bg-background` 上。
2. 左/中之间只保留一根 1px 的极淡竖线。
3. 右栏改成浮层：
   - 上、右、下留约 6px 边距，左侧 0～2px；
   - 1px 浮层边框，加很淡的阴影；
   - 填充用新的 `--surface-raised`；
   - 圆角约 8px。
4. 标题栏与底面同色，去掉下分隔线。右栏浮层从标题栏下方开始（即第 4 节的第一种方式）。
5. 文档正文继续限宽（现在是 48rem），左右留白保持宽松。
6. 先在一套浅色主题和一套深色主题上出效果，确认后再推广到其余主题。
