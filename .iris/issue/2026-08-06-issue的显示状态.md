目前issue的显示逻辑是这样的，就是Done和取消不显示，但是我认为你必须要增加一条规则，就是要是就是还有终端挂着，issue就必须在左栏显示，要不然容易丢终端

## 实现记录

左栏 issue 过滤现改为“活动 issue，或仍锚定会话的 issue”。会话按文档路径精确匹配，`active`、`idle` 和保留滚动区的 `exited` 会话都计入；只有关闭会话、使其从会话投影移除后，已完成或已取消的 issue 才会从左栏隐藏。issue 集合页的状态分类保持不变。

已通过类型检查、67 个单元测试和生产构建。

## 手工验收

* [x] 给一个有终端会话的 issue 设置 `Done` 或 `Canceled`，确认它仍显示在左栏，且点击后能回到原终端。

* [x] 关闭该 issue 的最后一个终端会话，确认它从左栏消失；未解决 issue 仍按原规则显示。
