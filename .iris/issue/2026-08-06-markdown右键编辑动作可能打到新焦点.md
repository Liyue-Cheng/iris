---
title: Markdown 右键编辑动作可能打到新焦点
status: Todo
---
WYSIWYG 编辑器的右键菜单里，“剪切 / 复制 / 粘贴 / 全选”不是立即执行，而是先等 50ms，再等一个 0ms 定时器，然后调用窗口级 WINDOW\_EDIT\_ACTION。

如果用户点完菜单项后立刻切换文档、打开弹窗或焦点落到别的输入框，旧编辑器的定时器不会取消。最后发出的窗口级 edit action 可能作用到新的焦点目标，而不是当时右键的那篇文档。

当前代码证据：

* src/renderer/components/doc/CrepeEditor.tsx 的 editAction 使用两层 window\.setTimeout。

* 组件卸载时没有清理这两个 timeout。

* 最终调用 WINDOW\_EDIT\_ACTION 时只带 action，没有带原始编辑器实例或文档校验。

需要处理：

* [ ] 把右键 edit action 做成可取消任务，组件卸载时取消。

* [ ] 执行前确认原 ProseMirror 仍存在且仍是目标编辑器。

* [ ] 尽量改成基于菜单关闭事件或明确焦点恢复后的确定性流程，不靠固定延迟。

* [ ] 补“右键后立即切文档/打开弹窗”的回归测试。
