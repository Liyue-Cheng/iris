切换到done cancell backlog之类的 我认为要是还有终端，最好是弹出一个对话框，就是确认是否关闭所有挂在下面的终端

## 实现记录（2026-08-06）

正文头部和 issue 列表的状态写入已统一走关闭状态动作。issue 切换到 `Done`、`Canceled` 等已解决状态，或 report 切换到 `Backlog` 时，如果仍有文档终端，会先弹出确认；确认后重新读取当前会话列表，关闭所有关联终端，再写入状态。取消时不关闭终端，也不修改状态。

issue 批量改状态会汇总所有选中文档的关联终端，只显示一次确认对话框。

* [x] 验证单篇 issue 在有多个终端时切换到 `Done` / `Canceled`：取消后保持原状，确认后终端全部关闭且状态成功切换

* [x] 验证 report 切换到 `Backlog`，以及多篇 issue 批量切换关闭状态时只出现一次确认并关闭全部关联终端
