## 实现方案

新增 `saas-light` / `saas-dark` 两个主题，移除 `light-pink`、`fairyfloss`、
`tokyo-night-day`。主题总数 15 → 14。

两个新主题沿用 Marina 语义 token 写法（`--color-bg-*` / `--color-text-*` /
`--color-danger` 等），因此直接挂到 global.css 里已有的共享 adapter 选择器上，
不需要新的 token 映射逻辑。配色走中性灰阶 + 蓝色强调色（Vercel / Linear 那一类
观感）：

| token | saas-light | saas-dark |
| --- | --- | --- |
| bg-primary | `#ffffff` | `#0a0a0a` |
| bg-secondary | `#fafafa` | `#121214` |
| bg-elevated | `#f4f4f5` | `#1a1a1d` |
| bg-hover | `#f1f1f3` | `#1f1f23` |
| bg-active（= `--accent` / `--input` / 边框来源） | `#dcdce0` | `#2a2a2f` |
| bg-strong | `#b4b4bb` | `#3f3f46` |
| text-primary | `#18181b` | `#ededed` |
| text-secondary | `#52525b` | `#a1a1aa` |
| text-muted | `#71717a` | `#8b8b93` |
| accent-special（= `--primary` / `--ring`） | `#2563eb` | `#60a5fa` |
| accent-secondary | `#ea580c` | `#fb923c` |
| danger / warning / success / info | `#dc2626` / `#b45309` / `#15803d` / `#0e7490` | `#f87171` / `#fbbf24` / `#4ade80` / `#38bdf8` |

正文与次要文字均满足 WCAG AA：`#71717a` on `#ffffff` ≈ 4.8:1，`#8b8b93` on
`#0a0a0a` ≈ 6.4:1。边框仍由 `bg-active` 经 `color-mix(... 38%)` 派生，和现有
主题保持同一套克制的分隔线语言。

`saas-light` 的 xterm 主题挂上 `LIGHT_EXTENDED_ANSI`，从而自动进入
`isLightTheme()` 分支、启用 4.5:1 的 minimumContrastRatio。

### 改动文件

- `src/shared/types.ts` — `ThemeId` 联合类型增删。
- `src/shared/terminal/terminal-colors.ts` — 终端前景/背景基色。
- `src/renderer/styles/global.css` — 新增两个 `[data-theme]` 调色板块，删除三个，
  更新共享 adapter 的选择器列表。
- `src/renderer/theme/xterm-themes.ts` — 新增两套 xterm 16 色 + 滚动条/光标色。
- `tailwind.config.cjs` — `darkMode` 选择器列表移除 `fairyfloss`、加入 `saas-dark`。
- `src/renderer/components/settings/SettingsView.tsx` — `THEMES` 列表与
  `THEME_COLORS` 预览色板；两个新主题排在 Rosé Pine 三件套之后。
- `src/renderer/components/layout/TitleBar.tsx` — 标题栏主题下拉的标签与图标。
- `src/main/settings-manager.ts` — `VALID_THEMES` 增删，并新增 `RETIRED_THEMES`
  迁移表。

### 老配置迁移

已经选中被删主题的用户，其 `settings.json` 会让 `validateSettings()` 抛错、
从而挡住启动。因此 `initialize()` 在校验前做一次改写并落盘：

- `tokyo-night-day` → `saas-light`
- `light-pink` → `saas-light`
- `fairyfloss` → `rose-pine-moon`

`update()` 路径不做迁移，仍然拒绝非法主题（渲染进程不该再送来这些 id）。

### 说明

`settings.darkKawaii` 这个 tone 文案随 `fairyfloss` 一起失去了使用者，但类型联合
和 i18n 键都保留着，没有清理。
