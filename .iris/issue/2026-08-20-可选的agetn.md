你将现在的agent加一个设置入口，作为一个正在开发的可选功能，没有打开的时候，不显示 用 iris agent 打开

## 实现

- 新增机器级 `experimental.irisAgent` 开关，默认值为 `false`；旧设置文件加载时会自动补为关闭。
- 在“设置 > Iris Agent”顶部增加“实验功能”开关，并明确标注功能仍在开发中、默认关闭。
- 开关关闭时，右侧会话面板的新增会话菜单和空状态启动区都不再显示“用 Iris Agent 打开”；已有 Agent Session 不会被强制终止。
- 主进程设置校验要求该开关必须为布尔值，中英文设置文案已同步。
