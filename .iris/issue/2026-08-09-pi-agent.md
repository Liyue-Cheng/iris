## 2026-08-09 安装记录

官方包为 `@earendil-works/pi-coding-agent`。当前最新版要求 Node.js
`>=22.19.0`，原环境为 Node.js `22.14.0`，因此首次 npm 安装自动选择了
`legacy-node20` 对应的 Pi `0.74.2`。

Node.js 升级命令如下。该命令会替换正在运行的 Node.js，因而会中断当前
Codex、Pi 或其他 Node.js 进程；必须先关闭相关终端，另开一个普通
PowerShell 执行：

```powershell
winget upgrade --id OpenJS.NodeJS.LTS --exact --accept-package-agreements --accept-source-agreements --silent
```

升级后的环境检查命令：

```powershell
node --version
npm --version
winget list --id OpenJS.NodeJS.LTS --exact --accept-source-agreements
```

Pi 最新版安装命令：

```powershell
npm install -g --ignore-scripts @earendil-works/pi-coding-agent@latest
```

安装验证与启动命令：

```powershell
pi --version
npm list --global @earendil-works/pi-coding-agent --depth=0
pi
```
