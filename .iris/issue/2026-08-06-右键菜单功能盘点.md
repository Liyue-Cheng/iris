## 盘点结果

项目共有 **4 类右键菜单**，覆盖 3 个场景。全部基于 Radix ContextMenu（`ui/context-menu.tsx`），无 Electron 原生菜单。

***

### 1. 文档行右键 — `DocContextMenu`

**触发位置：** 所有文档行（LensTree DocRow、RawTree 的 md 文件行、IssuePanel / ReportTimeline / SimpleList / StatusList 的集合视图行）

**菜单项：**

* 复制路径 — 将项目相对路径写入剪贴板

* 用默认程序打开 — `shell.openPath` → 操作系统关联的默认应用

* 在资源管理器中显示 — `shell.reveal-project-item` → 系统文件管理器

* ── 分隔线 ──

* 删除文件… — 打开 `DeleteDocDialog` 确认对话框

**评价：** 右键菜单只承载文件操作。创建会话不再放在这里；正确流程是先左键选中文档，再从右栏打开终端。所有文档表面仍共享同一组件。

***

### 2. 终端右键 — `TerminalView`

**触发位置：** 终端区域（右栏 xterm 实例）

**菜单项：**

* 复制 — 将选中文本写入剪贴板（无选区时 disabled）

* 粘贴 — 从剪贴板读取并 paste 到 PTY（含大粘贴 / ESC 注入 / 无 bracketed paste 多行的安全确认）

* ── 分隔线 ──

* 清屏 — `term.clear()`

* 搜索… — 打开终端搜索条 (Ctrl+F)

**可选行为：** 设置 `behavior.terminalRightClick` 可切换为 `'paste'` 模式（右键直接粘贴，不弹菜单）。

**评价：** 功能充分。复制/粘贴/清屏/搜索覆盖了终端场景的常见需求。

***

### 3. 编辑器右键 — `CrepeEditor`

**触发位置：** WYSIWYG 编辑器区域（中栏 Milkdown/Crepe 实例）

**菜单项：**

* 剪切 — `WINDOW_EDIT_ACTION('cut')` → webContents

* 复制 — `WINDOW_EDIT_ACTION('copy')`

* 粘贴 — `WINDOW_EDIT_ACTION('paste')`

* ── 分隔线 ──

* 全选 — `WINDOW_EDIT_ACTION('selectAll')`

**评价：** 标准编辑四件套，通过 IPC 走 webContents 确保剪贴板保真。功能基本充分。

***

### 4. 会话行右键 — `LensTree` + `RightPane`

**触发位置：**

* 左栏 LensTree 的 workspace hub 会话行（`WorkspaceSessionList`）

* 右栏 terminal banner 的当前会话标题

**菜单项：**

* 关闭会话 — `closeSession(s.id)`

**评价：** 功能极简，仅一个关闭操作。

***

## 缺失 / 可改进

* [x] **文档行右键增加「复制路径」**：将文档的项目相对路径复制到剪贴板，在终端中引用文档时很常用

* [ ] **文档行右键缺少「重命名」**：目前只能通过文件管理器或终端重命名

* [ ] **编辑器右键缺少「撤销 / 重做」**：标准编辑器右键菜单一般包含这两项

* [ ] **会话右键菜单过于单薄**：可考虑添加「重启会话」「复制会话标题」等操作

* [ ] **左栏工作区标题无右键菜单**：可考虑添加「在资源管理器中打开工作区文件夹」

* [ ] **非 md 文件行（RawTree）无右键菜单**：.bak / 图片等非 md 文件只是 inert 行，没有任何交互，可考虑至少提供「在资源管理器中显示」

* [ ] **SourceControlPanel（Git 面板）无右键菜单**：变更文件列表目前没有右键操作（如 stage / discard / diff 等），如果 Git 面板会扩展功能，右键菜单是自然的入口

## 多余项

未发现明显多余的右键菜单项或冗余实现。所有菜单项都有实际使用场景。
