提示词中提到不要新建文件，这个限制太强了，应该仅仅是不要新建被iris管理的文件，你现在修改

## 实施方案

将“未经请求不得新建任何文件”收紧为“未经请求不得新建 Iris 托管文件”：仅限制 typed folder 中的新文档及其 companion asset；用户已授权的实现任务所需源码、测试、配置和其他项目文件不受该条限制。在协议测试中固定这一边界，防止后续退回过宽表述。

## 实施结果

* 已修改 `src/main/iris-templates.ts` 中的软件协议模板，规则现在只禁止未经请求新建 typed folder 文档和 companion asset。

* 已明确用户授权实现所需的源码、测试、配置及其他项目文件不受该限制。

* 已在 `src/main/software-prompt.test.ts` 增加回归断言，同时防止旧的 `Never create a new file` 宽泛表述回归。

* 定向测试通过：`src/main/software-prompt.test.ts` 和 `src/main/i18n-protocol.test.ts`，共 2 个测试文件、11 项测试。

* 根目录 `AGENTS.md` 和 `CLAUDE.md` 的 `<iris-software>` 是 Iris 托管块，按协议不手工改写；后续由 Iris 的软件提示词同步机制从新模板更新。
