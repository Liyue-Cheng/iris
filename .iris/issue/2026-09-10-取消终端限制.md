status: Canceled

之前有个功能，就是左边的issue，要是右边有session即使done之类的也不从左栏移除，你现在取消这个功能，无论有没有，都会消除

## 实现记录

左栏 issue 镜面不再为「仍锚定会话」的已结束 issue 破例。`LensTree` 的 `TypeSection` 原先按「活动 issue 或仍锚定会话的 issue」过滤；现在只按 `isActiveIssue`（活动状态）过滤，`Done` / `Canceled` / `On Hold` 一律离开左栏，与该 issue 下是否还有终端或 Agent 会话无关。

* 改动点：`src/renderer/components/lens/LensTree.tsx`（`TypeSection`）——删掉 `projections.some(session => session.anchor.kind === 'document' && session.anchor.path === doc.path)` 保留分支，`TypeSection` 不再订阅 session 投影。
* `StatusDot`、工作区会话列表、右栏锚点模型都没动：会话本身、滚动内容和状态点仍然存在。
* 有意保留的副作用：已结束 issue 上的文档会话不再有左栏入口。仍可从 issue 集合页（状态筛选「全部」/「已解决」）打开该文档，右栏按文档锚点照常列出它的会话。
* 旧例外规则出自 issue「2026-08-06-issue的显示状态」，已在那篇文档追加说明。

验证：`npm run typecheck` 通过；`npm test` 568 passed（91 files）。

- [x] 该会话没有被关闭：从 issue 集合页找到这条已解决 issue，点开文档，确认右栏仍显示原会话并能继续交互。（已撤回，不再验收）
- [x] 活动 issue（`Todo` / `In Progress` / `In Review` / `Blocked`）不受影响，仍常驻左栏且状态点正常。（已撤回，不再验收）
