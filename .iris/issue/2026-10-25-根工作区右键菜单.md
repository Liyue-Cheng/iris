目前根工作区右键菜单没有反应，你现在设计合适的右键菜单

## 2026-10-25 原因

`LensTree.tsx` 的工作区标题行（`[chevron | 名称 | +]`）外层没有包 `ContextMenu`，所以右键没有反应。不只是根工作区，子工作区标题行也一样没有右键菜单。文档行（`DocContextMenu`）、hub 会话行、External 行都已经有右键菜单。

## 设计

根工作区和子工作区按「子工作区平权」原则共用同一个菜单 `WorkspaceContextMenu`。整行标题都能触发右键（包括 chevron 和 + 按钮）；菜单打开时，被右键的标题行会高亮（`data-[state=open]:bg-muted`）。

```
项目根                              ← 标签（子工作区显示工作区名）
▸ 新建会话            ▸ 用 Iris Agent 打开（实验开关开启时）/ 用 <launcher> 打开 …
▸ 新建文档            ▸ status / issue / report / misc
  新建子工作区...                     ← 父工作区预选为当前这个
─────────
  查看待办                            ← 根 = 全项目；子工作区 = 该工作区
  折叠文档区 / 展开文档区               ← 和 chevron 是同一个状态
─────────
  复制路径                            ← .iris 或 .iris/<sub>
  复制绝对路径                         ← <项目根>\.iris…
  在资源管理器中打开                    ← 打开工作区目录本身
  在资源管理器中显示                    ← 在父目录里选中工作区目录
```

取舍：

- **创建类放在最上面**：右键一个 hub，最常做的事是「在这里新建东西」。「新建会话」复用 + 按钮已有的入口（`openWorkspaceSession` / `openIrisAgent`）。没有配置任何 launcher、也没开启 Iris Agent 时，这一项显示为禁用。
- **新建子工作区**：复用 `CreateWorkspaceDialog`，新增可选参数 `defaultParent`，把父工作区预选为被右键的工作区。左栏工具栏的 FolderPlus 入口行为不变，仍然沿用上次的选择。
- **不提供删除 / 重命名工作区**：主进程目前没有对应的 API；而且删除工作区会连带删除整个文档树，属于高风险操作，不适合放进 lens-tree 的手势里。如果需要，另开 issue。
- **不放「关联外部文件」**：External 区自己的 + 按钮和拖放已经覆盖这个需求，而且它持有本地 inventory 状态，从标题行触发需要额外打通。
- 「打开」和「显示」不需要 `flushBeforeSwitch`：目标是目录，不涉及未保存的编辑。

## 实现

- `src/renderer/components/ui/context-menu.tsx`：新增 `ContextMenuSub / SubTrigger / SubContent`，样式与 dropdown-menu 的子菜单一致。
- `src/renderer/components/lens/LensTree.tsx`：新增 `WorkspaceContextMenu`，包住每个 `WorkspaceSection` 的标题行；`LensTree` 里持有一个新建子工作区对话框，通过 `onCreateChild` 往下传。
- `src/renderer/components/project/CreateWorkspaceDialog.tsx`：新增可选参数 `defaultParent`。
- `src/shared/i18n/resources.ts`：中英文各新增 5 个 key（`newDocumentMenu`、`newSubWorkspace`、`workspaceTodos`、`copyAbsolutePath`、`openFolder`）。
- `scripts/check-async-boundaries.mjs`：把 `projectStore.openTodos` 加进安全 void 名单。它和 `openCollection` / `selectRoot` 一样，是返回拒绝结果的导航函数。
- 新增测试 `src/renderer/lib/lens-workspace-menu.test.ts`（jsdom）。覆盖：根工作区标题能打开菜单；复制路径和绝对路径、打开、显示、待办的参数正确；子工作区的新建文档 / 新建会话 / 新建子工作区都作用在被右键的那个工作区；折叠和展开有效。
