# 产品截图与演示项目

为 README 和后续发布材料制作一组来自真实 Iris 界面的产品截图。截图必须使用虚构但合理的
演示项目数据，不包含私人路径、真实终端历史、密钥或其他本机敏感信息，不使用生成式图片
伪造产品功能。

当前先暂停执行，等待影响截图场景的阻塞 bug 修复后再继续，避免把已知缺陷固化进公开素材。

## 计划场景

* [x] 主工作区总览：左侧 lens tree、中间 issue 文档、右侧活动 Agent 会话。

* [x] 文档到 Agent 的动态工作流：从焦点文档启动 Agent 并进入焦点会话，使用 GIF 展示。

* [x] 集合与注意力视图：分组 Issue 面板或 Todo 面板，展示状态、workspace 和数量。

* [x] Agent 与提示词设置暂不制作，由用户决定从本轮公开素材中移除。

## 验收要求

* [x] 确认截图涉及的阻塞 bug 已修复，并从新的候选提交重新构建 Iris。

* [x] 使用独立 Electron profile 启动真实应用，不改动日常 Iris 设置、最近项目或 Agent 配置。

* [x] 复核演示数据的产品语义、状态机、checkbox、workspace 和 Git 状态是否合理。

* [x] 解决焦点终端截图中演示 Agent 输出未能稳定出现的问题。

* [x] 生成两张至少 1600×900 的清晰 PNG 和一张文字可读的工作流 GIF，并检查文字溢出、遮挡、空白和错误状态。

* [x] 逐张检查私人路径、真实用户名、终端历史、访问令牌和其他敏感信息；用户确认当前演示路径可以公开。

* [x] 将两张 PNG 和一张 GIF 接入中英文 README，并检查 GitHub Markdown 渲染结果。

* [x] 完成后回写原产品理解 issue 中的 README 截图任务；最终状态由用户决定。
