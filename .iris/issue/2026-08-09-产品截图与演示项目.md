# 产品截图与演示项目

为 README 和后续发布材料制作一组来自真实 Iris 界面的产品截图。截图必须使用虚构但合理的
演示项目数据，不包含私人路径、真实终端历史、密钥或其他本机敏感信息，不使用生成式图片
伪造产品功能。

当前先暂停执行，等待影响截图场景的阻塞 bug 修复后再继续，避免把已知缺陷固化进公开素材。

## 计划场景

- [ ] 主工作区总览：左侧 lens tree、中间 issue 文档、右侧活动 Agent 会话。
- [ ] 文档到 Agent 的工作流：焦点文档、typed header、启动器菜单或焦点会话。
- [ ] 集合与注意力视图：分组 Issue 面板或 Todo 面板，展示状态、workspace 和数量。
- [ ] Agent 与提示词设置：启动器配置和上下文注入状态。

## 验收要求

- [ ] 确认截图涉及的阻塞 bug 已修复，并从新的候选提交重新构建 Iris。
- [ ] 使用独立 Electron profile 启动真实应用，不改动日常 Iris 设置、最近项目或 Agent 配置。
- [ ] 复核演示数据的产品语义、状态机、checkbox、workspace 和 Git 状态是否合理。
- [ ] 解决焦点终端截图中演示 Agent 输出未能稳定出现的问题。
- [ ] 以至少 1600×900 的尺寸生成四张清晰 PNG，并检查文字溢出、遮挡、空白和错误状态。
- [ ] 逐张检查并移除私人路径、真实用户名、终端历史、访问令牌和其他敏感信息。
- [ ] 将最终图片接入 `README.md` 的四个预留位置，并检查 GitHub Markdown 渲染结果。
- [ ] 完成后回写原产品理解 issue 中的 README 截图任务；最终状态由用户决定。

## 2026-08-09 初始尝试

已在仓库本地创建 `.iris-screenshots/`，并通过 `.git/info/exclude` 排除，不进入 Git。目录中包含
虚构的 Atlas Commerce 演示项目、独立 Git 历史、隔离的 Iris 用户配置和 Playwright Electron
截图脚本。

当前脚本能够使用独立 Electron profile 打开真实 Iris，并能识别和取消首次项目提示词同步确认。
焦点文档和 Codex 启动器也能被自动选择，但演示终端输出尚未被稳定捕获，自动化在等待终端内容
时超时。尚未生成或接入任何正式截图，也未修改 README 的截图占位。
