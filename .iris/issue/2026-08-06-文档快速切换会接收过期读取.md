---
title: 文档快速切换会接收过期读取
status: Todo
---
快速点文档时，当前只用“路径是不是还一样”来判断一次 DOC\_READ 结果是不是过期。这个判断挡得住 A → B，却挡不住 A → B → A。

复现场景是：第一次点 A 的读取很慢；用户马上点 B，又点回 A；第二次 A 的读取其实才是最新的，但第一次 A 的旧结果也会因为 selectedPath 仍然等于 A 而被接受。这样旧内容可能覆盖新内容，尤其在文件刚被外部修改或后台保存刚完成时更危险。

当前代码证据：

* src/renderer/stores/project-store.ts 的 selectDoc 在发起 DOC\_READ 后，只检查 state.selectedPath === path。

* 代码没有给每次 selectDoc 分配 request token，也没有比较“这是第几次打开这个 path”。

需要处理：

* [ ] 给每次 selectDoc 分配单调递增的请求 token。

* [ ] DOC\_READ 成功和失败回调同时校验 path 与 token，只有最新请求能提交结果。

* [ ] 补 A → B 和 A → B → A 乱序完成测试。
