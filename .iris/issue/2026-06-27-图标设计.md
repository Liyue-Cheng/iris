为 Iris 设计一套品牌图标，并接入构建与界面。

## 概念：光圈花（aperture-bloom）

「Iris」一词同时是**鸢尾花**与**眼睛的虹膜（光圈）**。本应用的核心协议是
**聚焦**（`FOCUS_DOC`，一次专注一份文档），所以让花瓣像光圈一样向中心收
拢——中心那点金色即「当前聚焦的文档」。

- 三片明亮的「旗瓣」(standards) 用品牌紫 `--rp-iris`，构成在 16px 仍立得住
  的三叶轮廓。
- 三片柔和的「垂瓣」(falls) 用玫瑰色 `--rp-rose`，填满花形，小尺寸时自然隐退。
- 调色板完全取自应用主题 **Rosé Pine**，与界面同源。

## 交付物

主图标源文件（`build/`，矢量为准）：

- `build/icon.svg` — App 图标主稿（圆角底板 + 花标，含光晕/投影）。
- `build/mark.svg` — 透明背景纯花标（界面/favicon/关于页）。
- `build/mark-mono.svg` — 单色版（`currentColor`，托盘/水印）。
- `build/wordmark.svg` — 横向组合「花标 + Iris」字标。

光栅化产物（由 `scripts/gen-icons.mjs` 生成，`npm run gen:icons`）：

- `build/icon.ico` — Windows 多尺寸图标（16/24/32/48/64/128/256，已校验）。
- `build/icon.png` — 512px，electron-builder 跨平台兜底 / Linux 图标。
- `build/preview.png` — 评审用拼版（不随包发布）。

接入：

- `electron-builder.yml` → `win.icon: build/icon.ico`（打包 exe / 安装器图标）。
- `src/main/app-main.ts` → `BrowserWindow` 的 `icon`（开发期任务栏；打包后用
  builder 的 exe 图标，`build/` 不入 asar 故仅开发期生效）。
- `src/renderer/components/layout/IrisMark.tsx` → 标题栏「Iris」字样左侧的内联花标。
- 新增依赖（devDependencies）：`@resvg/resvg-js`、`png-to-ico`（仅光栅化用）。
