左栏现在还是没有很好的实现一个对齐，就是现在目录根的三角形和下面的status还是没有完全对齐，你现在开始修改

## 根因

左栏两层折叠三角的左内边距不一致：

- 工作区表头（目录根）的三角按钮是 `px-1`（图标左缘 4px）；
- 下面 `status`/`issue`/`report`/`misc` 的三角按钮是 `px-2`（图标左缘 8px）。

两者父容器都从同一左缘起算，所以这 4px 的差就是「根三角和 status 没对齐」——status 那一排整体往右缩了 4px。

## 改动

`src/renderer/components/lens/LensTree.tsx` 的 `TypeSection` 折叠三角按钮：
`px-2 py-0.5` → `shrink-0 px-1 py-0.5`。两层三角的左缘都落在 4px，垂直对齐；
顺手加 `shrink-0` 与表头三角保持一致，窄栏时不被挤压。`npm run typecheck` 通过。

## 手工验收

- [ ] `npm run dev` 下，左栏目录根的 ▾ 与正下方 `status` 的 ▸/▾ 左缘对齐
- [ ] 子工作区表头三角与其内部类型区三角同样对齐
- [ ] 窄栏时三角不被挤压、不错位
