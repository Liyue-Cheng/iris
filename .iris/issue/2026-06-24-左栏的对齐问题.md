左栏现在还是没有很好的实现一个对齐，就是现在目录根的三角形和下面的status还是没有完全对齐，你现在开始修改

## 根因

左栏两层折叠三角的左内边距不一致：

- 工作区表头（目录根）的三角按钮是 `px-1`（图标左缘 4px）；
- 下面 `status`/`issue`/`report`/`misc` 的三角按钮是 `px-2`（图标左缘 8px）。

两者父容器都从同一左缘起算，所以这 4px 的差就是「根三角和 status 没对齐」——status 那一排整体往右缩了 4px。

## 改动

`src/renderer/components/lens/LensTree.tsx` 的 `TypeSection` 折叠三角按钮：
`px-2 py-0.5` → `shrink-0 px-1 py-0.5`。两层三角的左缘都落在 4px，垂直对齐；
顺手加 `shrink-0` 与表头三角保持一致，窄栏时不被挤压。`npm run typecheck` 通过。

## 第二轮：图标列仍不对齐

三角对齐后，三角**右边的图标列**还是错位：

- 表头容器有 `gap-1`，三角与 `FolderRoot` 图标之间隔 4px；
- `TypeSection` 行容器没有 gap，类型图标（`Gauge`/`CircleDot`/…）紧贴三角。

所以每个类型图标比表头的 `FolderRoot` 图标整体左移 4px——这就是「图标不对齐」。

改动：`TypeSection` 行容器 `flex items-center pr-1` → `flex items-center gap-1 pr-1`，
让类型图标列与表头图标列同起点。`npm run typecheck` 通过。

## 第三轮：文本列对齐 + 增大图标-文本间距

全面排查各行的「文本左缘」x 坐标（相对各行内容盒，单位 px）：

| 行 | 旧 图标→文本 gap | 旧 文本起点 |
| --- | --- | --- |
| 根表头名称 | `gap-1.5`(6) | 46 |
| 类型标签 | `gap-1`(4) | 44 ← 比名称差 2px |
| 文档行 | `gap-1.5`(6) | 26 |
| 空占位 `px-7` | — | 28 ← 比文档文本差 2px |

两处 2px 抖动就是「文本还有问题」。统一把所有 图标/圆点 → 文本 的 gap
提到 `gap-2`(8px)（既增大间距，又消抖动）：

- 类型标签按钮 `gap-1` → `gap-2`
- 根/子表头名称按钮 `gap-1.5` → `gap-2`
- 文档行 / 会话行 `gap-1.5` → `gap-2`

结果：根名称文本 = 类型标签文本 = 48；文档文本 = 空占位 = 28，全部对齐。
`npm run typecheck` 通过。
