title: agent直接开始
status: Done
---
实现这项新的功能：在agent挂在文档而不是工作区下面，且文档内容不为空的时候，即使agent没有输入任何东西，也可以直接点击开始，然后会以一个默认输入内容，例如请根据文档内容开始工作 之类的，启动agent

实现结果：

- 文档锚点的新 Iris Agent 会话在没有输入内容时可以直接点击开始；主进程确认文档内容非空后，使用“请根据文档内容开始工作”作为默认指令启动。
- 工作区锚点、已有对话以及空文档仍要求输入明确任务，规则在主进程发送链路中强制执行。
- 发送按钮在新建文档会话的空输入状态显示为开始操作；普通输入仍按原流程发送。

验证：

- [x] 新增并通过文档空输入启动与工作区空输入拒绝的 session-manager 回归测试。
- [ ] 手工确认：打开一个有内容的文档，创建 Iris Agent 会话后直接点击开始，并确认默认指令已进入对话。
