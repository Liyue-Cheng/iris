## 背景

Iris 为满足官方 Pi SDK `0.84.1` 的 Node `>=22.19.0` 运行时要求，正在将桌面基线从 Electron 31 迁移到精确锁定的 Electron 43.4.0。该迁移不应阻塞 Iris Agent 第一阶段主力开发；基础安装与自动化验证通过后即可继续，剩余平台风险由本 Issue 独立跟踪并在以后人工检查。

本 Issue 只负责升级后的兼容性和发布风险，不承载 Iris Agent 产品实现。发现问题时在这里记录证据，具体修复可按范围另建 Issue。

## 已知风险

* Electron 内置 Chromium 从 126 跨到 150，编辑器、输入法、拖放、剪贴板、终端渲染、GPU 和焦点行为可能出现自动化测试覆盖不到的变化。

* Electron 内置 Node/V8 和 native ABI 已变化。`node-pty@1.1.0` 虽提供 Windows prebuild，但 Iris 当前关闭 electron-builder 的 native rebuild，必须检查开发态和真实安装产物中的 ConPTY 加载与生命周期。

* 现有 `electron-vite@2.3.0`、Vite 5 和 `electron-builder@26.15.2` 暂未随 Electron 升级。自动 build/smoke 可以证明基础链路，不等于 portable/NSIS、asar unpack、签名和安装后启动全部可靠。

* Electron/Chromium 升级可能改变包体积、冷启动、内存、GPU 选择和后台节流表现，需要在代表性 Windows 环境测量。
