# 默认提示词与提示词管理

Iris 现在使用两个静态入口块和会话动态上下文。提示词块不携带版本、协议号或哈希，
也不存在历史默认识别和模板升级链。

## 真相之源

- **软件提示词**：`src/main/iris-templates.ts` 中的
  `SOFTWARE_PROMPT_TEMPLATE` 是唯一真相之源。正文包含目录语义、frontmatter、
  issue/report 状态机、GFM checkbox、文档 companion asset 规则和 Markdown 写作约束。
- **状态机结构**：`src/shared/document-status.ts` 是 issue/report 状态值的代码真相
  之源；软件提示词、文档骨架和 renderer 的状态控件共同引用它。
- **项目提示词**：项目根入口文件中的 `<iris-project>` 正文是盘上真相之源。
  Iris 不提供默认正文；没有该块就是未设置。
- **会话动态上下文**：`FOCUS_DOC` 或 `IRIS_WORKSPACE_PATH` 由
  `focus-context.ps1` 在 SessionStart 时读取。

静态块格式固定为无属性 XML 标签：

```text
<iris-software>
内置软件正文
</iris-software>

<iris-project>
用户设置的项目正文
</iris-project>
```

## 入口同步

`AGENTS.md` 是标准入口；`CLAUDE.md`、`GEMINI.md`、`.cursorrules`、
`.windsurfrules`、`.clinerules` 和 `.github/copilot-instructions.md` 仅在文件已存在时
参与维护。同步只替换 Iris 标签块，保留块外文本。

软件块按内置正文做精确比较：缺文件为 `no-entry`，缺块为 `missing`，正文不同或标签
仍带属性为 `drifted`，完全一致为 `ok`。打开项目只报警，不自动覆盖；初始化或设置页
的显式同步会恢复内置正文。

项目块按盘上内容锁相：

- 首次打开时没有项目块即为 `missing`。
- 只有一个唯一非空正文时，该正文静默导入并镜像到 `AGENTS.md` 与所有现存 vendor
  入口；旧标签属性会在镜像时清理。
- 多个入口正文不同则为 `conflict`，Iris 不覆盖任何文件。设置页展示每份正文，用户
  选取或编辑后保存即可统一所有入口。
- 会话期间，一份相对上次同步基线的外部修改会成为新真相并扇出；同一批出现多个
  不同修改则进入冲突。
- 在设置页保存空正文会删除所有入口的 `<iris-project>` 块。

入口同步不生成 `AGENTS.md.bak`、`CLAUDE.md.bak` 或其他临时死副本。持久化设置使用的
`JsonStore` 滚动备份属于另一套数据安全机制，不受此规则影响。

## 初始化与注入

`project:init` 创建四个 typed folders 并同步软件块，不再创建项目级样式配置。它不再
创建或读取项目级 `.iris/CONVENTIONS.md`，也不读取
`~/.iris/templates/CONVENTIONS.md`。

SessionStart hook 不再重复输出 `<iris-software>` 或 `<iris-project>`。静态两层由 agent
入口文件直接提供；hook 只输出 `<iris-workspace>` 或 `<iris-focus>` 中与当前会话实际
相关的动态内容。没有 Iris 会话变量的普通终端不输出内容。

## 设置页与接口

- `software-prompt:state` 返回每个入口的软件块状态和项目提示词的
  `missing` / `synced` / `conflict` 状态。
- `software-prompt:sync-entry` 在用户确认后恢复一个入口的软件块。
- `project-prompt:sync` 保存项目文本并扇出到所有入口。
- `evt:prompt:changed` 在外部同步或冲突变化后刷新设置页。
- `software-prompt:preview` 分开展示静态软件块、项目正文和 hook 动态预览。

用户提示词/机器事实层已经完整删除：不存在 `MACHINE_CONVENTIONS_TEMPLATE`、
`machine:*` IPC、标题栏安装入口、设置页用户层、`<iris-user>` 注入或
`src/main/machine-layer.ts`。现存的 `~/.iris/CONVENTIONS.md` 即使由旧版本创建，也不会
再被 Iris 读取、展示、迁移或删除。

## 已知边界

- 每个入口目前只管理首个同名标签块。
- 项目提示词 watcher 只覆盖已知入口文件名。
- hook 脚本当前是 Windows PowerShell 实现，尚无 POSIX 版本。
