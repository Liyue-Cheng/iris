# 开发与构建

日常命令均在仓库根目录的 PowerShell 中执行。

## 安装依赖

首次安装或依赖变更后：

```powershell
npm install
```

使用锁定依赖进行干净安装：

```powershell
npm ci
```

## 开发

启动 Electron 开发环境：

```powershell
npm run dev
```

指定开发端口：

```powershell
$env:IRIS_DEV_PORT = 17273
npm run dev
```

预览生产构建：

```powershell
npm run preview
```

## 检查与测试

```powershell
npm run typecheck
npm run check:async
npm test
npm run test:watch
```

Vitest 同时最多运行 4 个 worker，每项测试默认超时为 15 秒。测试包含真实 Git、
PTY 进程及 journal fsync，避免把 Windows 进程启动或磁盘竞争误判为业务失败。
类型检查覆盖主进程、预加载、renderer 与共享类型，也包含相应目录中的测试文件。

Windows 原子替换遇到 `EPERM`、`EACCES` 或 `EBUSY` 时最多尝试 5 次，等待合计
500ms；失败后保留原文件并清理本次临时文件。终端监督在终端启动记录提交完成后
才开始计时，回归测试通过延迟持久化覆盖首次输出不能丢失的竞态。

边界检查通过；全量 100 个测试文件、643 项测试通过；9 个 JavaScript 维护脚本
语法检查、顶层依赖完整性和 `git diff --check` 通过。自动检查不替代界面验收：

## 构建与验证

