# 开发与构建

Iris 是一个 Windows 优先的 Electron 应用，使用 TypeScript、React 18、electron-vite 和 Vitest。项目要求 Node.js 20 或更高版本，日常命令均在仓库根目录执行。

## 安装依赖

```powershell
npm install
```

`front-cpu` 当前通过 `file:../dashboard/cpu-pipeline` 引用本机相邻目录。首次安装前需确保该路径存在。

## 开发服务器

```powershell
npm run dev
```

该命令启动 electron-vite 开发环境和 Electron 窗口，并为渲染进程启用热更新。开发端口会从 `17273`、`9273`、`7273`、`3273`、`8273`、`5173` 中选择首个可绑定端口。

需要指定端口时：

```powershell
$env:IRIS_DEV_PORT = 17273
npm run dev
```

若指定端口不可用，配置会继续尝试候选端口。

## 代码检查与测试

```powershell
npm run typecheck
npm test
```

`typecheck` 分别检查主进程、preload 和 Web 渲染进程；`test` 运行一次 Vitest 测试集。开发测试可使用监听模式：

```powershell
npm run test:watch
```

## 构建与预览

```powershell
npm run build
```

构建前会自动运行类型检查，产物写入 `out/`，其中包含 `main/`、`preload/` 和 `renderer/`。

构建完成后可启动预览：

```powershell
npm run preview
```

也可执行启动冒烟测试：

```powershell
npm run smoke
```

`smoke` 针对 `out/` 中的现有构建运行，因此应先执行 `npm run build`。

## Windows 打包

```powershell
npm run dist
```

该命令依次执行类型检查、应用构建、旧版本发布目录清理和 electron-builder 打包，目标架构为 Windows x64。产物位于 `dist/release/<version>/`：

- `Iris-<version>-portable.exe`：免安装便携版。
- `Iris-<version>-setup.exe`：可选择安装目录的 NSIS 安装包。

## 其他维护命令

重新生成应用图标：

```powershell
npm run gen:icons
```
