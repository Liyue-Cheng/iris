# 开发与构建

日常命令均在仓库根目录的 PowerShell 中执行。

## 安装依赖

首次安装或依赖变更后：

```powershell
npm install
```

使用锁定依赖进行干净安装：

```powershell
npm ci
```

## 开发

启动 Electron 开发环境：

```powershell
npm run dev
```

指定开发端口：

```powershell
$env:IRIS_DEV_PORT = 17273
npm run dev
```

预览生产构建：

```powershell
npm run preview
```

## 检查与测试

```powershell
npm run typecheck
npm run check:async
npm test
npm run test:watch
```

## 构建与验证

```powershell
npm run build
npm run smoke
npm run metadata:check
npm run agent:worker-check
```

Windows x64 发布构建：

```powershell
npm run dist
```

## 许可证

生成或检查第三方许可证声明：

```powershell
npm run licenses:generate
npm run licenses:check
```

## 其他维护

```powershell
npm run gen:icons
npm run gen:lucide-icon-names
```
