## 当前背景

目前没有笔记本电脑，正在评估是否购买 MacBook Air。购买目的不只是为 Iris 测试 macOS，也包括获得一台便携开发设备。因此，这项购买应同时从日常使用价值和 Iris 跨平台价值判断，不能只按“测试机”衡量。

当前已有 Windows 开发环境。如果保留 Windows 主机，MacBook Air 可以承担移动开发、macOS 实机调试、签名、公证和发布验收，Windows 主机继续覆盖 Windows 独占软件与 Windows 版本测试，Linux 则主要通过 CI 或单独环境覆盖。这是较合理的三平台组合。

## 当前结论

如果确实需要一台随身笔记本，并会继续保留 Windows 主机，MacBook Air 值得购买。它与 Iris 的 Electron、TypeScript、Node.js、Git、终端和 AI CLI 工作负载匹配，同时能补齐当前缺失的 macOS 实机环境。

如果 MacBook Air 必须成为唯一电脑，而工作中仍严重依赖 Windows 独占的 EDA、CAD、驱动、CUDA 或其他专业软件，则不适合直接用它完全替代 Windows 设备。Apple Silicon 上的 Windows ARM 虚拟机不能等价替代真实 Windows x64 环境。

不应仅仅因为 Iris 将来需要 macOS 版本而仓促购买。没有 Mac 也可以先通过 GitHub Actions 的 macOS runner 完成依赖安装、测试、类型检查、构建和初步打包，并通过云 Mac、借用设备或测试用户进行阶段性验证。当 macOS 开发进入每周多次实机调试时，拥有本地 Mac 才会显著缩短反馈周期。

## 推荐配置

- 最低建议：Apple Silicon、16 GB 内存、512 GB SSD。
- 更从容的开发配置：24 GB 内存、512 GB 或 1 TB SSD。
- 不建议选择 8 GB 内存或 256 GB SSD；IDE、Electron、浏览器、Node 依赖、Docker 和多个 agent CLI 会较快触及限制。
- 内存优先于小幅 CPU 升级，因为内存和硬盘在购买后基本不能升级。
- 13 英寸更适合频繁携带；15 英寸更适合长时间写代码，选择主要取决于便携性和屏幕空间，而不是性能。
- MacBook Air 没有风扇，但普通 Electron 构建、测试和原生模块编译足够使用。持续大型编译、多虚拟机或本地大模型负载更适合 MacBook Pro 或桌面设备。

## 与其他方案比较

### MacBook Air

同时解决笔记本需求和 macOS 实机需求，便携、续航好、安静。适合将 macOS 作为常态开发和发布平台，但购置成本高于临时测试方案。

### Mac mini

如果已有满意的移动设备，Mac mini 是更便宜的固定 macOS 构建与测试机，可以通过远程桌面或 SSH 使用。但当前没有笔记本，因此它不能解决移动办公需求，综合价值不如 MacBook Air。

### GitHub Actions

适合持续执行 macOS 构建、自动测试、原生依赖验证、签名和公证，不要求拥有 Mac。它不能充分替代标题栏、Dock、Finder 拖放、输入法、Retina、Terminal.app 和安装流程等桌面体验测试。

### 云 Mac 或借用设备

适合在购买前完成第一次实机验证。MacStadium、AWS EC2 Mac 等运行在真实 Apple 硬件上，但长期频繁使用的费用和操作延迟不适合持续日常开发。

## macOS 正式发行的额外成本

面向普通用户直接分发 macOS 应用，通常需要加入 Apple Developer Program，并配置 Developer ID 签名、hardened runtime、entitlements 和 notarization。开发者账号与是否购买 Mac 是两个独立决策；账号和签名流程可以在项目接近公开发布时办理，没有必要因为开始跨平台开发就立即投入。

即使 CI 能完成签名和公证，正式发布前仍需在真实 macOS 设备上检查：

- DMG 或 zip 的安装、首次启动与 Gatekeeper 行为。
- 原生标题栏、交通灯、Dock、菜单和全屏。
- Finder 文件拖放、剪贴板、文件选择器和中文输入法。
- Zsh、Terminal.app、`node-pty` 和各类 agent CLI。
- Retina 缩放、休眠唤醒、应用退出和残留进程。

## 购买时机

当前不需要为了开始跨平台改造而立即购买。可以先完成 POSIX 平台抽象，并让 macOS CI 构建通过。随后使用一次云 Mac、借用设备或外部测试验证应用确实能启动和工作。

满足以下条件后，购买 MacBook Air 的收益会比较明确：

- 本身已经确定需要一台笔记本电脑。
- Windows 主机仍会保留，两个平台可以互补。
- Iris 的 macOS 包已经能够构建，接下来需要频繁实机调试。
- 日常工作主要是代码、终端、文档和轻中度构建，而不是持续重负载计算。
- 预算允许选择至少 16 GB 内存和 512 GB SSD，而不需要为低配勉强购买。

## 建议

在保留 Windows 主机的前提下，如果购买笔记本的需求真实存在，优先考虑 16 GB 内存、512 GB SSD 起步的 Apple Silicon MacBook Air；预算允许且会同时运行较多开发工具时，优先升级到 24 GB 内存。

如果尚未确定是否真正需要移动设备，则先使用 CI 和临时 Mac 验证 Iris，不为单一软件测试提前购机。最终购买的核心理由应是“长期需要一台便携开发电脑，并能顺带补齐 macOS 能力”，而不是“没有 Mac 就无法开发 macOS 版本”。
